# Renewable Energy Orchestrator

An agentic decision-and-control platform for renewable generation, battery storage, demand
flexibility, grid interconnection and market participation — built to the ET AI Hackathon
"Agentic Edition" Problem 4 brief and the 8-document client spec in `renewable_energy_orchestrator/`.

**The implementation lives in [`platform/`](platform/README.md) — start there.** It has its own
README with the full quickstart (Docker Compose), repository layout, model-provider configuration
(OpenRouter by default), and how to run the test suite and the live demo script.

```
renewable_energy_orchestrator/   Client spec documents (BRD/PRD/FRD/TRD/...) — reference only
platform/                        The implementation — see platform/README.md
```
